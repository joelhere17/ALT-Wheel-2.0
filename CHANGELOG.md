# Changelog

## 2.0.0 - Alt Wheel 2
The second version of Alt Wheel, rebuilt as a desktop-style app.
- Files live on a desk as icons. Drag one away and the wheel opens under your pointer.
- Glass-style wheel with a pop-in animation and a center pill that shows file size, then the hovered format.
- Convert wheel: PNG, WEBP, HEIC, TIFF, AVIF, BMP, PDF, DOCX, JPG, TXT (depends on the source file).
- New Tools wheel: Compress, Metadata, Edit, Annotate, Add BG, Crop, Redact.
- Space (or Tab, Shift) switches between the Convert and Tools wheels mid-drag.
- Save one file, or Save all as a zip.
- Project split into separate CSS and JavaScript files, with an end-to-end test.

## 1.0.0 - Alt Wheel
The first version: put one file in the middle of a wheel, drag it toward a format, and save the result.
